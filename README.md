# Prova

## Como executar

1. Crie um ambiente virtual Python python -m venv venv
2. Ative o ambiente virtual: source venv/bin/activate (no Windows: venv\Scripts\activate)
3. Instale as dependências: pip install -r requirements.txt
4. Execute o servidor: python manage.py runserver
5. Acesse a aplicação em http://127.0.0.1:8000/
